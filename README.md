# پل

**سیم‌کارت گوشی اندرویدت، روی آیفون**

تماس‌ها، پیامک‌ها و مخاطبین گوشی اندروید رو مستقیم روی آیفون داشته باش.
گوشی دوم توی کیف می‌مونه، کارها با آیفون.

[**خرید اشتراک — @polantenbot**](https://t.me/polantenbot) · [**دانلود**](../../releases/latest)

## امکانات
- 💬 **پیامک** — دریافت با اعلان، جواب دادن از آیفون، انتخاب سیم ۱ یا ۲
- 📞 **تماس** — تماس ورودی با صفحه‌ی اصلی تماس آیفون، جواب دادن، رد کردن و شماره‌گیری
- 👥 **مخاطبین و تاریخچه‌ی تماس** — همه‌ی مخاطبین اندروید روی آیفون، با امکان ذخیره در مخاطبین آیفون
- 🔒 **بدون سرور و بدون اینترنت** — دو گوشی مستقیم با بلوتوث به هم وصل می‌شن و اطلاعاتت جایی نمی‌ره
- 🔋 **سبک** — روی اندروید در پس‌زمینه با کمترین مصرف باتری کار می‌کنه

## پیش‌نیاز
- گوشی اندروید با **Android 10** به بالا
- آیفون با **iOS 17** به بالا
- دو گوشی نزدیک هم (برد بلوتوث)

## نصب

### اندروید
1. فایل **Pol.apk** رو از بخش [دانلود](../../releases/latest) بگیر و نصب کن.
2. اپ رو باز کن و **دادن مجوز** رو بزن.
3. اگه مجوز پیامک خاکستری بود (اندروید ۱۳ به بالا): اطلاعات برنامه ← منوی ⋮ ← **Allow restricted settings**، بعد دوباره مجوز بده.
4. بهینه‌سازی باتری رو برای پل خاموش کن.
5. اتصال رو روشن کن. کد ۶ رقمی نمایش داده می‌شه.

### آیفون
1. **SideStore** رو نصب کن (یک بار با کامپیوتر).
2. در SideStore این سورس رو اضافه کن و **پل** رو نصب کن:
   ```
   https://raw.githubusercontent.com/peadeyme/pol/main/sidestore/source.json
   ```
3. پل رو باز کن، گوشی اندروید رو انتخاب کن و کد ۶ رقمی رو وارد کن.
4. هر ۷ روز اپ رو در SideStore تمدید کن. پل خودش ۲ روز قبل یادآوری می‌کنه.

> اگه نصب برات سخته، از طریق ربات با پشتیبانی هماهنگ کن تا از راه دور برات نصب بشه.

## اشتراک
- **۷ روز آزمایشی رایگان** بعد از نصب
- خرید و تمدید فقط از ربات تلگرام: **[@polantenbot](https://t.me/polantenbot)**
  1. پلن رو انتخاب کن.
  2. **کد دستگاه** رو از بخش «اشتراک» اپ اندروید کپی کن و بفرست.
  3. پرداخت کن و رسید رو بفرست.
  4. کد لایسنس رو در اپ اندروید وارد کن.
